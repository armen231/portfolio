# Краткое описание
## проект № 0
Одностраничное веб-приложение, использующееся как стартовая страница для просмотра подробностей и открытия проектов.

## проект № 1
Одностраничное веб-приложение, представляющее технику компании.

## проект № 2
Многостраничное веб-приложение магазина женской одежды.

## проект № 3
Многострочное веб-приложение строительной компании.

## проект № 4
Одностраничное веб-приложение, использующееся как ИАС (информационно-аналитическая система) и ЭС (экспертная система), применяемая для создания базы знаний и осуществления поиска по базе знаний предложений стран для путешествия на основе предпочтений клиента.
 
***

 # Функционал проектов
## проект № 0
Просмотр проектов.

## проект № 1
1. Масштабирование сайта под все устройства.

## проект № 2
1. Масштабирование сайта под все устройства.
2. Функционал добавления товара в корзину.
3. Взаимодействие с корзиной товаров.

## проект № 3
1. Масштабирование сайта под все устройства.
2. Смена темы сайта (дневная/ночная).
3. Смена языка (русский, английский).
4. Взаимодействие с фильтрацией и сортировкой по параметрам. Например, перейдя по "Главная" -> "Каталог" -> "Дом/Бани/Беседки/Гаражи".
5. Использование слайдера. Например, перейдя по "Главная" -> "Каталог" -> "Дом/Бани/Беседки/Гаражи" -> выбрать услугу.

## проект № 4
1. Поиск информации по параметрам.
2. Вывод результата по поиску.
3. Добавление и удаление элементов (городов) / параметров (например, тип отдыха, бюджет поездки и т. д.) / фактов (название и описание параметра).
4. Просмотр вложенных в виде иерархического отображения сущностей (интерфейс поддерживает трёхуровневую вложенность: «Элемент» (страны) → «Параметр» (тип отдыха, бюджет и др.) → «Факт» (конкретные значения с описанием)).

# Инструкция по установке и запуску
## проект № 0
1. Скачать папку командой "git clone" projects/project0/original_project.
2. Запустить редактор кода где в рабочей области будет папка original_project.
3. Запустить терминал -> команду "npm i".
4. Запустить проект "npm run start".

## проект № 1, № 2, № 3 
1. Скачать соответствующую папку.
2. Запустить файл index.html в браузере.
